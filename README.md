# Youtube 转文章 · skill

把 YouTube / 播客的口语字幕，整理成一篇能直接阅读的中文文章。

**不是摘要，不是总结。** 目标读感接近正式出版的中文非虚构书，
信息保留率 ≥99%——读稿子的人，获得的信息量应当和看视频的人一样多。

---

## 快速开始

### 安装

把整个文件夹放到你的 skills 目录：

```bash
# 用户级（所有项目可用）
~/.workbuddy/skills/subtitle-to-article/

# 或项目级
你的项目/.workbuddy/skills/subtitle-to-article/
```

### 使用

对你的 AI 助手说：

```
整理成文章
```

然后给它一份字幕文件（`.md` / `.txt`）。或者直接 @ 文件路径：

```
把这个整理成文章 @字幕.md
```

### 校验成稿

```bash
python scripts/check_article.py 成稿.md              # 检查
python scripts/check_article.py 成稿.md --strict     # 严格模式（不合格则退出码 1）
python scripts/check_article.py 目录/                # 批量
```

脚本**零依赖**，只用 Python 标准库，Python 3.6+，跨平台。

## 目录结构

```
subtitle-to-article/
├── SKILL.md                          主文档：原则 / 流程 / 注意事项
├── README.md                         本文件
├── scripts/
│   └── check_article.py              成稿校验器（零依赖）
├── references/
│   ├── 01-原则详解.md                 保留什么 / 删什么 / 禁止什么
│   ├── 02-英文处理判定表.md            什么留英文、什么必须译
│   ├── 03-排版与 Obsidian 兼容.md      标题 / 加粗 / 链接规则
│   ├── 04-常见事故与踩坑.md            12 个真实事故复盘
│   └── 05-交付自检清单.md              交稿前逐项打勾
└── examples/
    ├── example-subtitle.md           输入样例（口语字幕）
    └── example-article.md            对应的输出样例
```

`SKILL.md` 是唯一的必需文件（AI 加载它就知道怎么做）。
`references/` 是需要深入时才翻的，`scripts/` 是交付前必跑的，
`examples/` 用来确认"做成什么样算对"。

## 它解决的三个真问题

**1. 只翻译，不总结。**
普通做法是丢给模型说"总结一下这个视频"，得到的是 500 字要点。
这个技能要的是全文整理——讲者用五分钟解释一个观点，你就得保留五分钟的推导。

**2. 中文要像中文。**
禁止中英混排残留：普通名词、动词、形容词、口语词一律译出，
只有人名 / 作品名 / 专业术语三类可留英文。

**3. 排版能真的渲染出来。**
Obsidian 对中文加粗有个坑（CommonMark 的 flanking 规则按英文空格设计），
很容易在编辑模式露出裸星号。这个技能给了明确判据 + 自动校验脚本。

---

## 校验项一览

| # | 检查 | 能自动判定 |
|---|---|---|
| 1 | 首行 skill 署名 | ✅ |
| 2 | 小标题未被编号 | ✅ |
| 3 | 加粗闭合 + Obsidian flanking 连接性 | ✅ |
| 4 | 英文残留 | ⚠️ 只列清单，需人工判定 |
| 5 | 无 `[文字](url)` 写法（公众号兼容） | ✅ |
| 6 | 无占位符残留 | ✅ |
| 7 | 文末有「原文：」来源块 | ✅ |
| 8 | 中文之间无多余空格 | ✅ |

脚本会自动跳过代码块、行内 code、URL、图片链接、frontmatter、
首行署名、文末原文行——这些地方出现英文是正常的。

**脚本查不了的**（内容完整性、语言自然度、有没有夹带私货）必须人工过，
清单在 `references/05-交付自检清单.md`。

## 需要你配置的地方

`SKILL.md` 第 8 节列了所有可改项，默认值是原作者的习惯：

| 项目 | 默认 | 说明 |
|---|---|---|
| 存放目录 | `05 - 笔记/` | 改成你的笔记目录 |
| 成稿命名 | 《演讲原题的中文译名》 | 用书名号包裹 |
| 链接处理 | 拆成代码块 | 为适配微信公众号；发博客可保留标准链接 |
| 首行署名 | 保留 | 想去掉也行 |

改这些**不影响技能效果**，只是适配你自己的环境。
