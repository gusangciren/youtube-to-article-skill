# 01 · 原则详解：保留什么、删什么、禁止什么

---

## 一、什么算「实质内容」（必须保留）

判断标准：**删掉它，读者会不会少知道一件事？**

| 类型 | 说明 | 例子 |
|---|---|---|
| 观点 | 讲者的主张、判断 | "我认为目标属于失败者" |
| 案例 | 完整细节，包括背景、过程、结果 | "他当时在伯克利读 MBA，同时……" |
| 推导过程 | 讲者怎么一步步得出结论 | "所以如果 A 成立，那 B 就不可能……" |
| 举例与反例 | 包括失败的例子 | "也有人这么做过，结果失败了，因为……" |
| 数字与时间 | 具体金额、人数、年份、百分比 | "第一年做了 50 万美元" |
| 人名与机构名 | 全名、头衔、身份 | "沃伦·巴菲特"、"伯克利哈斯商学院" |
| 逻辑连接 | 观点之间的因果关系 | "正是因为这点，所以……" |
| **对谈的交锋** | 反驳、追问、纠正、笑点、自嘲 | "主持人插话：这不就是运气吗？" |

**特别注意最后一条**：访谈/对谈类稿件里，只保留主讲者的单边观点是错的。
追问和反驳往往正是内容最有价值的部分。

## 二、可以删的三类（只有这三类）

### 1. 纯口语填充词

```
um、uh、er、ah
you know、I mean
kind of、sort of
basically、actually、literally（当填充词用时）
like（当填充词用时）
那个、就是、然后……（中文口语里的同类）
```

⚠️ 注意：这些词**有实义时不能删**。
比如 "actually" 表示「事实上，与预期相反」时是实质内容，要译出来。

### 2. 无意义的自我重复

```
原文：这非常重要，非常非常重要，我再说一次，非常重要。
整理：这非常重要。
```

⚠️ 区分「重复强调」和「分层次展开」：
如果讲者每次重复都加了新信息（换个角度、加个例子），那不是重复，要保留。

### 3. 与主题无关的闲聊

- 打招呼、寒暄
- 开场玩笑、暖场
- 现场互动（"后面那位举手的"）
- 技术故障的插话（"麦克风没声音？"）
- 广告口播、求点赞关注

⚠️ 如果"玩笑"里藏着一个观点或一个例子，那就不是闲聊，保留。

## 三、禁止行为（清单）

| ❌ 禁止 | 说明 |
|---|---|
| 删除重要内容 | 见第一节 |
| 删除案例或压缩案例细节 | 案例只留结论是最常见的偷懒 |
| 删除解释/推导过程 | 只给结论不讲为什么 |
| 删除举例 | 尤其反例 |
| 删除观点之间的连接 | 会让文章变成散落的要点 |
| 为简洁而压缩 | 「五句话压成一句」是明确禁止的 |
| 添加讲者没说过的观点 | 不可以借整理之名夹带私货 |
| 添加"学习心得"/"编者按" | 输出只要文章本身 |
| 输出摘要或点评 | 用户要的是全文整理 |
| 留占位符 | 成稿即完稿 |

## 四、正反例对照

### 例 1：口语 → 书面（保留全部信息）

**字幕原文：**
> so, um, you know, when I was at Berkeley, right, I was doing my MBA and, like, I had this idea that, you know, goals are for losers, and, uh, I mean, everyone was talking about SMART goals and all that stuff, but I was like, no, systems, right? you need systems.

**❌ 错误做法（压缩了）：**
> 他在伯克利读 MBA 时提出，目标属于失败者，人需要系统。

**✅ 正确做法：**
> 我在伯克利哈斯商学院读 MBA 的时候，产生了一个想法：目标属于失败者。
> 那时候所有人都在谈 SMART 目标之类的东西，但我的看法恰恰相反——
> 你需要的是系统。

（保留了：地点、身份、主张、对照物「SMART 目标」、转折关系）

### 例 2：重复的处理

**原文：**
> and this is really important, this is really really important, I'm gonna say it again, it's super important that you understand the difference between goals and systems

**✅ 整理：**
> 有一点极其重要，请务必理解：**目标和系统的区别**。

### 例 3：对谈交锋必须保留双方

**原文：**
> A: so basically anyone can do this
> B: wait, really anyone? I don't buy that
> A: okay, fine, not anyone, but way more people than think they can

**✅ 整理：**
> **任何人都能做到这件事。**
>
> ——真的任何人吗？我不太买账。
>
> 好吧，不是任何人。但能做到的远比自以为能做的人要多。

## 五、自检金句

> **读起来越顺，越要回去核对有没有漏。**

成稿"结构完整、节奏舒服"不代表做完了——
那往往意味着你把它整理得太干净了。回去逐段比对源文件。
