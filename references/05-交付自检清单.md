# 05 · 交付自检清单

打印出来，每篇交稿前逐项打勾。

---

## A. 动笔前

- [ ] 核对源文件三项（标题 / URL / 行数），确认不是重复提交、内容没被换过
- [ ] 已处理过且成稿还在？→ 不要重写，只做事实性升级
- [ ] **分段通读源文件全文**，确认时间戳走到视频末尾
- [ ] 讲者姓名、身份、头衔已核实

## B. 内容完整性（最重要）

- [ ] 源文件**每一段**在成稿里都有对应
- [ ] 所有案例保留了完整细节（背景 / 过程 / 结果）
- [ ] 数字、金额、年份、人数、百分比没丢
- [ ] 人名、机构名、地名全在，且准确
- [ ] 推导过程保留了（不只给结论）
- [ ] 反例、失败案例保留了
- [ ] **对谈类：双方的话都保留了**（追问 / 反驳 / 纠正 / 笑点）
- [ ] 开头人物介绍里的**并列身份/头衔**没漏
- [ ] 没有添加讲者没说过的观点

## C. 只删了杂质

- [ ] 只删了三类：口语填充词 / 无意义重复 / 离题闲聊
- [ ] 没有为了简洁压缩内容
- [ ] 没有把五句话并成一句

## D. 语言

- [ ] 读起来是中文，不是"用中文字写英文"
- [ ] 没有翻译腔、没有保留英语语法结构
- [ ] 普通英文词已全部译出（跑脚本看清单逐项确认）
- [ ] 术语首次出现给了「中文（English）」，之后统一中文
- [ ] 作品名用了《中文名》（原文）格式
- [ ] 职位名译中且全篇统一（首席执行官 / 人力资源 / 公关……）
- [ ] **文末整理说明也扫过了**（包括人名）

## E. 排版

- [ ] 小标题**没有**编号（除非原文本身是清单体）
- [ ] 段落偏密，一个意思一段
- [ ] 加粗克制，只标关键一两句
- [ ] 加粗在 Obsidian **编辑模式**下能正常解析（跑脚本 `[3]`）
- [ ] 链接已拆成代码块（若发公众号）
- [ ] 首行有 skill 署名
- [ ] 文末有「原文：」来源块
- [ ] 没有占位符残留

## F. 交付

- [ ] 跑过 `python scripts/check_article.py 成稿.md --strict`
- [ ] 输出的是完整文章，没有附加摘要 / 点评 / 改动说明
- [ ] 文件已写入（文件名不含 Windows 保留字符）
- [ ] 同一次演讲的两份稿（整理稿 / 风格稿）命名可区分，没有互相覆盖

---

## 一键命令

```bash
python scripts/check_article.py 成稿.md --strict
```

退出码 0 = 格式项全部通过；
退出码 1 = 有不合格项（脚本会打印具体行号）。

脚本查不了的部分（内容完整性、语言自然度、是否夹带私货）在 B / C / D 三节，
**必须人工过**。
