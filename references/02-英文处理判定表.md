# 02 · 英文处理判定表

成稿里**不得残留普通英文词**。本文给出判定标准和高频词表。

---

## 一、可以保留英文的三类

| 类别 | 例子 | 写法 |
|---|---|---|
| **专有名词** | 人名、地名、品牌、公司、机构、产品名 | 直接保留：`Airbnb`、`Paul Graham`、伯克利 |
| **作品名** | 书、电影、节目、文章 | 《中文名》（English Name），首次出现即给译名 |
| **学科/专业术语** | 它本身就是知识点 | 首次「中文（English）」，之后统一中文 |

### 判断流程

```
这个英文词……
├── 是人名/地名/品牌/公司/产品？  → 保留
├── 是作品名？                    → 《中文名》（原文）
├── 是专业术语？
│   └── 首次出现 → 中文（English）
│       之后     → 只用中文
└── 其他一切                      → 必须译成中文
```

## 四、长稿（访谈/对谈）的特殊策略

外文保留严格限于三类：

1. **人名与作品名**（首次出现括注原文）
2. **学科/专业术语**（它本身就是知识点，必须留）
3. **确实译不出的专名**（俚语词、碑铭体、词典学例词、声音对比例句等）

**所有引文例句一律译成中文**，只给极少数标志性短句括注英文原文。

**长引文（诗行、大段台词）不要保留英文**——
否则里面的虚词（the / of / and …）会被逐个抓出来，
要么把整段砍掉，要么逐个判断，工作量爆炸且效果差。

---

## 五、残留高发区 ⚠️

按经验，英文残留最常出现在这些位置：

| 位置 | 典型漏网 | 对策 |
|---|---|---|
| **文末整理说明**（自己写的那段） | 术语解释、原名、缩写（API / CTA / 品牌英文名） | 写完单独再扫一遍 |
| 讲者中文译名旁边 | 顺手把英文真名留在正文 | 真名只放文末「原文：」行 |
| 并列枚举的词组 | 译了三个漏掉第四个 | 枚举项逐个点名核对 |
| 引文、例句 | 图省事直接贴英文原文 | 一律译中 |
| 表格单元格 | 表格内容容易被漏扫 | 表格单独过一遍 |

**规则**：文末整理说明里**连人名也要写成中文**
（例如别写「Alex Hormozi」，写「亚历克斯·霍尔莫齐」）。

## 六、自查方法

1. 跑 `scripts/check_article.py`，它会列出所有 ≥3 个连续字母的英文词及出现次数
   （已自动跳过代码块、URL、图片链接、frontmatter、首行署名、文末原文行）。
2. 对着清单逐个判断：属于那三类 → 放行；否则 → 译掉。
3. 拿不准的，**倾向译掉**。留英文的代价（读起来割裂）大于译错的代价。
